## What is CSS?

CSS (Cascading Style Sheets) is a web technology used to format and style HTML documents and provides stylistic behaviors using CSS animations. CSS is used to control the layout, colors, fonts, and other visual aspects of a web page.

CSS enables us to separate the structure & content (HTML) of a document from its presentation. This concept of separation of concerns is widespread throughout software development because it helps make programs more maintainable and provides better code reuse.

Like most skills related to development, your CSS skills will continually develop over time with each front-end project you’re involved with.

## Why use CSS?

There are many reasons to use CSS, including:

  - **Separation of concerns**: CSS separates the presentation of a web page from its structure. This makes it easier to maintain and update web pages, and it allows developers to create more reusable styles.

  - **Consistency**: CSS can be used to create consistent styles across multiple web pages. This is important for creating a professional and polished look for a website.

  - **Accessibility**: CSS can be used to make web pages more accessible to people with disabilities. For example, CSS can be used to increase the font size of text or to add alternative text for images.

  - **Performance**: CSS can be used to improve the performance of web pages by reducing the amount of HTML code that needs to be downloaded and rendered.


CSS is an essential tool for any software engineer who wants to create web pages. It allows developers to control the presentation of their web pages without having to modify the HTML code. CSS is also important for creating consistent, accessible, and performant web pages.
